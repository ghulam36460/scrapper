OPTIMIZATION RECOMMENDATIONS:
-----------------------------
If you want FASTER performance:

1. Reduce crawl pacing:
   - Edit mode config: max_seconds_per_page
   - Lower from 30s to 15s
   - Remove artificial delays

2. Use "balanced" mode instead of "max":
   - max mode = all tools + maximum stealth = slower
   - balanced mode = fewer tools + medium stealth = faster
   - lite mode = minimal tools + low stealth = fastest

3. Reduce limit:
   - Currently: limit=10 targets
   - For testing: limit=3 targets

4. Disable some features:
   - llm_enabled: false (saves LLM processing time)
   - archive_raw_html: false (saves disk I/O)
   - enable_search_discovery: false (less discovery overhead)

5. Reduce browser pool:
   - MAX mode uses 4 browser contexts
   - Balanced mode uses 2
   - Less browsers = less overhead
