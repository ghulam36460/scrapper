# ASAGUS Mailer - Run Commands

## Quick Start (Windows)
Double-click: start.bat

## Manual Start

### Backend (Terminal 1):
cd asagus-mailer\backend
uvicorn main:app --reload --host 0.0.0.0 --port 8000

### Frontend (Terminal 2):
cd asagus-mailer\frontend
npm run dev

## Access URLs
- Frontend: http://localhost:3000
- Backend API: http://localhost:8000
- API Documentation: http://localhost:8000/docs
- Health Check: http://localhost:8000/health

## First Time Setup

### 1. Install Backend Dependencies:
cd asagus-mailer\backend
pip install -r requirements.txt

### 2. Install Frontend Dependencies:
cd asagus-mailer\frontend
npm install

### 3. Generate SECRET_KEY (if .env doesn't exist):
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

Then create .env file in project root with:
SECRET_KEY=<your_generated_key>

## Stop Application
- Close both terminal windows
- Or press Ctrl+C in each terminal

## Troubleshooting

### Port Already in Use:
Backend (8000): netstat -ano | findstr :8000
Frontend (3000): netstat -ano | findstr :3000
Kill process: taskkill /PID <process_id> /F

### Database Reset:
Delete asagus.db file (will recreate on next startup)

### Clear Frontend Cache:
cd asagus-mailer\frontend
rmdir /s /q .next
npm run dev

## Production Build

### Backend:
cd asagus-mailer\backend
uvicorn main:app --host 0.0.0.0 --port 8000 --workers 4

### Frontend:
cd asagus-mailer\frontend
npm run build
npm start
