## 🚀 HOW TO USE

### Quick Start (5 minutes)

```bash
# 1. Start system
cd asagus-scraper-v3
./start_all.sh

# 2. Open browser
# Frontend: http://localhost:3000
# Backend API: http://localhost:8000/docs

# 3. Create job in UI
# - Click "Run" tab
# - Enter query and location
# - Set mode to "max"
# - Click "Start"

# 4. Download results
# - Click "Records" tab
# - Click "Download CSV"
# - Or use API: GET /api/records/export/csv
```

### For Production

```bash
# 1. Configure environment
cd asagus-scraper-v3
nano .env

# Add:
# ENABLE_INFRA_PERSISTENCE=true
# POSTGRES_URL=postgresql://...
# LLM_PROVIDER=anthropic
# ANTHROPIC_API_KEY=sk-ant-...
# RESIDENTIAL_PROXY_URL=http://...

# 2. Start system
./start_all.sh

# 3. Verify
curl http://localhost:8000/api/runtime/persistence-stats

# 4. Run jobs!
```
